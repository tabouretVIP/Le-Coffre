# Documents mathématiques partagés
Il s'agit d'un projet contenant toutes nos notes de cours et syllabus avec lesquels nous avons travaillé durant tout notre cursus à l'UMONS. C'est un projet collectif visant à centraliser nos documents pour faciliter notre apprentissage des mathématiques. Chacun est invité à partager tout document qu'il estime posséder un intérêt mathématique ou pédagogique.
L'objectif de ce projet est d'une part de permettre un suivi studieux de nos cours et d'autre part de permettre le partage de notre intérêt commun autour des mathématiques et donc d'acquérir un apprentissage proactif guidé par nos curiosités.
En l'état, ***Le Coffre*** contient des notes de la majorité des cours de bachelier en option informatique. Tout étudiant en master ou en option physique est invité à partager ses documents pour que le plus grand nombre puisse en profiter. Plus bas, pour les débutants, nous détaillons comment utiliser GitHub pour faciliter l'accès à ce projet. 

### Fonctionnement

## Projet : Exercices PCPC 
Le Coffre n'est pas seulement un projet de lecture mais aussi un projet d'action. Nous proposons des fiches d'exercices par niveau nommées "*PCPC*". Cela consiste en des fiches d'exercices présentant un réel intérêt conceptuel. Cela permet d'améliorer sa capacité de réflexion plutôt que de simplement appliquer des méthodes vues au cours (une IA vous remplacera sinon). ## Comment ça marche pour vous

Pas besoin d'être un pro pour utiliser ce dépôt. Voici l'essentiel.

### Juste consulter / télécharger

C'est le cas le plus courant, et c'est très simple :

- **Lire un fichier** : cliquez dessus depuis GitHub, les PDF s'affichent directement dans le navigateur.
- **Télécharger un seul fichier** : ouvrez-le, puis cliquez sur le bouton **Download** (icône ⬇️ en haut à droite).
- **Tout télécharger d'un coup** : bouton vert **Code** > **Download ZIP**.

C'est tout. Vous pouvez travailler tranquillement sur votre ordinateur.

### Proposer un ajout ou une correction

Le dépôt est **protégé** : personne ne peut modifier directement le contenu principal. Toute modification nous est envoyée pour validation, donc **vous ne risquez pas de casser quoi que ce soit**. 

**La méthode la plus simple (dans le navigateur, sans rien installer) :**

1. Allez dans le dossier concerné sur GitHub.
2. Cliquez sur **Add file** > **Upload files** (ou sur le crayon pour modifier un fichier existant).
3. Glissez-déposez vos fichiers.
4. En bas, choisissez **"Create a new branch and start a pull request"**.
5. Cliquez sur **Propose changes**, puis **Create pull request**.

Nous recevons une notification, on relit, et on intègre. Vous n'avez plus rien à faire.

**Si vous préférez une application (Windows) :**
(Si vous êtes sous Linux, vous n'avez pas besoin de tuto, mais n'hésitez pas à demander à une IA si vous avez des problèmes.)

Installez [GitHub Desktop](https://desktop.github.com/) : tout se fait en quelques clics, sans ligne de commande.

| Action | Où cliquer |
|---|---|
| Récupérer le projet | **Clone a repository** |
| Créer une branche | **Current branch** > **New branch** |
| Enregistrer ses modifs | Écrire un résumé en bas à gauche > **Commit** |
| Envoyer sur GitHub | **Push origin** |
| Proposer l'intégration | **Create Pull Request** |

> **En cas de doute, demandez-nous.** Mieux vaut poser une question que de ne rien envoyer !
