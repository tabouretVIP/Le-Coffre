# Documents mathématiques partagés
Il s'agit d'un projet contenant toutes nos notes de cours et syllabus avec lesquels nous avons travaillé durant tout notre cursus à l'Umons. C'est un projet collectif visant à centraliser nos documents pour faciliter notre apprentissage des mathématiques. Chacun est invité à partager tout document qu'il estime posseder un interret mathématique ou pédagogique.
L'objectif de ce projet est d'une part de permettre un suivi studieux de nos cours et d'une autres part de permettre le partage de notre interet commun autour des mathématiques et donc d'acquérir un apprentissage pro-actif guidé par nos curiosité.
En l'état, ***Le Coffre*** contient des notes de la majorité des cours de bachelier en option informatique. Tout étudiant en master ou en option physique est invité à partager ses documents pour que le plus grand nombre puisse en profiter. Plus bas, pour les débutants, nous détaillons comment utiliser github pour facilité l'accès à ce projet.

## Projet: Exercices PCPC 
Le Coffre ce n'est pas seulement un projet de lecture mais aussi un projet d'action. Nous proposons des fiches d'éxercices par niveau nommées "*PCPC*". Cela consistes en des fiches d'exercices présentant un réel intéret conceptuel. Cela permet d'améliorer sa capacité de réfléxion plutôt que de simplement appliquer des méthodes vues au cours (une IA vous remplacera sinon). Pour motiver ce projet nous offrons de fabuleuses récompenses pour ceux qui réaliseront ses exercices : 

| Récompense | Condition |
|---|---|
| 🏆 Une tête de pioche | Premier à finir **toutes** les fiches d'exercices |
| 🍚 500g de riz | Premier à finir **une** fiche d'exercice |
| 🍺 Une bière offerte | S'investir et résoudre quelques exercices |

## Comment ça marche pour vous (débutants bienvenus 👋)

Pas besoin d'être développeur pour utiliser ce dépôt. Voici l'essentiel.

### Juste consulter / télécharger

C'est le cas le plus courant, et c'est très simple :

- **Lire un fichier** : cliquez dessus depuis GitHub, les PDF s'affichent directement dans le navigateur.
- **Télécharger un seul fichier** : ouvrez-le, puis cliquez sur le bouton **Download** (icône ⬇️ en haut à droite).
- **Tout télécharger d'un coup** : bouton vert **Code** > **Download ZIP**.

C'est tout. Vous pouvez travailler tranquillement sur votre ordinateur, rien ne casse.

### Proposer un ajout ou une correction

Le dépôt est **protégé** : personne ne peut modifier directement le contenu principal. Toute modification m'est envoyée pour validation, donc **vous ne risquez pas de casser quoi que ce soit**. 🙂

**La méthode la plus simple (100 % dans le navigateur, sans rien installer) :**

1. Allez dans le dossier concerné sur GitHub.
2. Cliquez sur **Add file** > **Upload files** (ou sur le crayon ✏️ pour modifier un fichier existant).
3. Glissez-déposez vos fichiers.
4. En bas, choisissez **"Create a new branch and start a pull request"**.
5. Cliquez sur **Propose changes**, puis **Create pull request**.

Je reçois une notification, je relis, et j'intègre. Vous n'avez plus rien à faire.

**Si vous préférez une application (Windows) :**

Installez [GitHub Desktop](https://desktop.github.com/) : tout se fait en quelques clics, sans ligne de commande.

| Action | Où cliquer |
|---|---|
| Récupérer le projet | **Clone a repository** |
| Créer une branche | **Current branch** > **New branch** |
| Enregistrer ses modifs | Écrire un résumé en bas à gauche > **Commit** |
| Envoyer sur GitHub | **Push origin** |
| Proposer l'intégration | **Create Pull Request** |

> 💡 **En cas de doute, demandez-moi.** Mieux vaut poser une question que de ne rien envoyer !
